# Pandas Wanderlust 🌍

Trip itinerary planner + expense tracker. Built with React, TanStack Router, Supabase, and Tailwind CSS.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Make sure your `.env` file has:
   ```
   VITE_SUPABASE_URL=https://ypyydruzkfvuqgqeyiza.supabase.co
   VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
   ```

3. Run dev server:
   ```bash
   npm run dev
   ```

## Stack
- **React 19** + **TypeScript**
- **TanStack Router** (file-based, SPA)
- **Supabase** (auth + database)
- **Tailwind CSS v4**
- **shadcn/ui** components
- **Vite 7**
